# CloudGuard Intelligence Dashboard

CloudGuard is a robust, lightweight, and free-to-host intelligence agent designed for cloud architects and administrators. It monitors official Microsoft 365 and Azure global endpoints to provide real-time service updates, high-priority security announcements, and AI-powered executive summaries.

## 🚀 Key Features

- **Multi-Provider AI Intelligence**: Support for both **Google Gemini 2.0 Flash** and **Groq (Llama 3.3)**.
- **Transparent Fallback Logic**: Automatically switches to Groq if Gemini hits quota limits (HTTP 429), ensuring uninterrupted service.
- **Hybrid Data Acquisition**: Integrates directly with the official Microsoft 365 Release Communications API to fetch roadmap items, reducing LLM token usage and increasing accuracy.
- **Persistent Caching**: Implements a `localStorage` caching system (1-hour TTL) that allows the dashboard to load instantly and work offline.
- **Advanced Dashboard UI**: Integrated client-side search and category filtering (Azure, M365, Security) for efficient browsing of roadmap updates.
- **Automated Reporting**: Executive summaries generated by AI, ready to be dispatched as email briefings.
- **Zero-Cost Hosting**: Fully client-side architecture designed for static hosting (Vercel, GitHub Pages) without needing a backend.

## 🛠️ Implementation Details

### Intelligence Service
The application uses a modular `intelligenceService.ts` that handles multiple AI providers. It leverages **JSON mode** to ensure structured and reliable parsing of AI responses, eliminating brittle regex-based extractors.

### Robust Environment Handling
CloudGuard supports pre-configured API keys via environment variables, making it ideal for sharing private deployments:
- `API_KEY`: Your Google Gemini API Key.
- `GROQ_API_KEY`: Your Groq API Key.

The app intelligently detects available keys and defaults to the best available provider.

## 📥 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- A Google Gemini API Key or a Groq API Key (both are free for hobbyist usage)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rouzbeh81/cloudguard-monitor.git
   cd cloudguard-monitor
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables (Optional):**
   Create a `.env` file or set these in your deployment platform (like Vercel):
   ```env
   API_KEY=your_gemini_key_here
   GROQ_API_KEY=your_groq_key_here
   ```

4. **Run in development mode:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```

## ⚙️ Configuration

You can configure your intelligence preferences directly within the app by clicking the **Configure Notifications** button. This allows you to:
- Switch between AI providers.
- Manage API keys locally (stored securely in `localStorage`).
- Set your preferred email recipient for reports.
- Enable/disable automated daily digest schedules.
